# PawOS

Добро пожаловать в PawOS — кастомную операционную систему для ПК на базе x86 и Android 5.0 (Lollipop). Проект создан для глубокой модификации интерфейса и превращения старого «железа» в уютное, быстрое и уникальное рабочее пространство.

## О проекте
PawOS — это не просто стандартный дистрибутив с новыми обоями. Здесь перерабатывается практически вся система, чтобы адаптировать мобильную платформу под удобное десктопное управление с помощью мыши и клавиатуры.

## Особенности и планы:
* Глубокая кастомизация: Полностью переработанное меню настроек, измененная системная информация и уникальный интерфейс.
* Собственный софт: Набор фирменных приложений, разработанных специально для этой системы.
* Виджеты (в разработке): Уникальные элементы рабочего стола для быстрого доступа к функциям.
* Оптимизация: Легковесная работа на старых ПК и ноутбуках благодаря надежной базе.

## Техническая база
* Архитектура: x86
* Основа: Android 5.0 (Linux-ядро)
* Статус: В активной разработке
